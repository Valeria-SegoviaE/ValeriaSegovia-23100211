# API REST con Express y API Key

Servidor HTTPS desarrollado con Express. Incluye autenticación mediante API Key,
validaciones de solicitudes y rutas para usuarios, alumnos y archivos.

## Generar la documentación

Instala JSDoc globalmente con `npm install -g jsdoc` y ejecuta:

```sh
npm run doc
```

La documentación HTML se genera en la carpeta `out/`.
